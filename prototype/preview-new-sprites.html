🚶 Walk vs Run 비교

Walk frames (run 기반 가공)
walk_0 (←run1)
walk_1 (←run0 ×0.94)
walk_2 (←run3)
walk_3 (←run2 ×0.94)
Run frames (원본)
run_0
run_1
run_2
run_3
run_4
▶ Walk — 느린 프레임(160ms) + 느린 이동(1px/tick)

▶ Run — 빠른 프레임(80ms) + 빠른 이동(3px/tick) — 비교
const sprint = quickly(moveForward);
